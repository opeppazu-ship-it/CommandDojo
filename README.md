# コマンド道場（CommandDojo）

格闘ゲーム（ストリートファイター6・テリー）のコマンド入力を練習する Windows 用ソフトです。

## ダウンロード

👉 **[最新版をダウンロード](https://github.com/opeppazu-ship-it/CommandDojo/releases/latest)**

ページの下の「Assets」にある **CommandDojo_v0.3.zip** を押すとダウンロードできます。

## はじめかた

1. ダウンロードした ZIP を右クリック →「プロパティ」→ 下の「ブロックの解除」にチェック → OK
2. ZIP を右クリック →「すべて展開」
3. 中の **CommandDojo.exe** をダブルクリック
   - 「WindowsによってPCが保護されました」と出たら「詳細情報」→「実行」
   - 何もインストールしなくても動きます（Windows 10 / 11、64ビット）

## できること

- **技練習**：テリーの必殺技・SA のコマンドを判定します（★PERFECT ◎GREAT ○GOOD ✕MISS）
  - 失敗すると理由が出ます（方向がぬけた・おそい・別の技が出た など）
- **コンボ練習**：「これ ▶ これ ▶ これ」の順番どおりに入れる練習
- **棒人間**：入力どおりに動いて、練習相手に技が当たります
- 1P / 2P（左右）の切りかえ、おまかせモード、成功率の記録
- コントローラー（パッド・アケコン・レバーレス）とキーボードに対応

## 注意

- 判定のフレーム数は、ネットの検証で分かっている値です（公式の数字ではありません）
- 棒人間の動きや当たり方は、見て分かるための作りものです
- 非公式のファンメイドツールです。株式会社カプコン・株式会社SNKとは関係ありません
